# Документация системы инлайн-кнопок для хадисов

## Обзор

Система инлайн-кнопок обеспечивает навигацию по книгам и хадисам сборника «Сахих аль‑Бухари». Каждая кнопка имеет свой порядковый номер и соответствует конкретной книге или хадису.

## Структура системы

### 1. База данных (`data/db/data_base.py`)

База данных содержит таблицу `hadis` со следующей структурой:
- `id` - уникальный идентификатор записи
- `book_number` - номер книги (1-95)
- `book_title` - название книги
- `hadis_number` - номер хадиса в книге
- `hadis_text` - текст хадиса

**Основные функции:**
- `get_books()` - возвращает список всех книг (номер, название)
- `get_book_title(book_number)` - возвращает название книги по номеру
- `get_hadiths_by_book(book_number)` - возвращает все хадисы из указанной книги
- `get_hadis_by_book_and_number(book_number, hadis_number)` - возвращает конкретный хадис

### 2. Система кнопок (`keyboard_bt/button.py`)

#### 2.1. Кнопки книг (`inline_book_keyboard`)

**Функция:** `inline_book_keyboard(page: int = 1) -> InlineKeyboardMarkup`

**Описание:**
- Создает инлайн-кнопки для выбора книги из сборника
- Книги разбиваются на страницы (по 15 книг на странице)
- Каждая кнопка имеет формат: `№{порядковый_номер}. {название_книги}`
- Порядковый номер рассчитывается глобально (не только на странице)

**Формат кнопки:**
- Текст: `№{порядковый_номер}. {название_книги}`
- Callback data: `book_{book_number}`
- Пример: `№1. Введение: Откровение (хадисы 1-7)`

**Особенности:**
- Название книги укорачивается до 50 символов для удобства отображения
- Удаляется часть с "(хадисы ...)" для более компактного вида
- Если название слишком длинное, оно обрезается с добавлением "..."

**Навигация:**
- Кнопки "⬅️ Предыдущие" и "Следующие ➡️" для переключения страниц
- Callback data для навигации: `bpage_{page_number}`
- Кнопка "◀️ Назад" для возврата к главному меню

#### 2.2. Кнопки хадисов (`inline_hadis_list_keyboard`)

**Функция:** `inline_hadis_list_keyboard(book_number: int, page: int = 1) -> InlineKeyboardMarkup`

**Описание:**
- Создает инлайн-кнопки для выбора хадиса из выбранной книги
- Хадисы разбиваются на страницы (по 20 хадисов на странице)
- Каждая кнопка имеет формат: `№{порядковый_номер}. Х{номер_хадиса}. {начало_текста}`
- Порядковый номер рассчитывается глобально (не только на странице)

**Формат кнопки:**
- Текст: `№{порядковый_номер}. Х{номер_хадиса}. {начало_текста}`
- Callback data: `hadis_{book_number}_{hadis_number}`
- Пример: `№1. Х2. Передал нам Мухаммад ибн Салам, сказав: сообщил нам...`

**Особенности:**
- Текст хадиса укорачивается до 45 символов для удобства отображения
- Если текст не помещается, он обрезается с добавлением "..."
- Максимальная длина кнопки - 64 символа (лимит Telegram)
- Если текст слишком длинный, отображается только номер: `№{порядковый_номер}. Х{номер_хадиса}`

**Навигация:**
- Кнопки "⬅️ Предыдущая" и "Следующая ➡️" для переключения страниц
- Callback data для навигации: `hlist_{book_number}_{page_number}`
- Кнопка "◀️ Назад к книгам" для возврата к списку книг

### 3. Обработчики команд (`router/commands/comand_hadis.py`)

#### 3.1. Обработка выбора книги (`handle_book`)

**Callback data:** `book_{book_number}`

**Действия:**
1. Извлекает номер книги из callback_data
2. Получает название книги из базы данных
3. Отображает список хадисов выбранной книги с названием книги в заголовке
4. Формат заголовка: `Книга {book_number}: {название_книги}\n\nВыберите хадис:`

#### 3.2. Обработка выбора хадиса (`handle_hadis`)

**Callback data:** `hadis_{book_number}_{hadis_number}`

**Действия:**
1. Извлекает номер книги и номер хадиса из callback_data
2. Получает полный текст хадиса из базы данных
3. Отображает текст хадиса
4. Предоставляет кнопку "◀️ Назад к хадисам книги" для возврата

#### 3.3. Пагинация

**Книги:**
- Callback data: `bpage_{page_number}`
- Обработчик: `handle_book_page`
- Переключает страницы списка книг

**Хадисы:**
- Callback data: `hlist_{book_number}_{page_number}`
- Обработчик: `handle_hadith_page`
- Переключает страницы списка хадисов в выбранной книге

## Порядковые номера кнопок

### Книги
- Порядковый номер рассчитывается глобально для всех книг
- На странице 1: №1, №2, №3, ..., №15
- На странице 2: №16, №17, №18, ..., №30
- И так далее

**Формула:** `порядковый_номер = (page - 1) * page_size + индекс_на_странице + 1`

### Хадисы
- Порядковый номер рассчитывается глобально для всех хадисов в книге
- На странице 1: №1, №2, №3, ..., №20
- На странице 2: №21, №22, №23, ..., №40
- И так далее

**Формула:** `порядковый_номер = (page - 1) * page_size + индекс_на_странице + 1`

## Callback data структура

| Тип кнопки | Callback data формат | Пример |
|------------|---------------------|--------|
| Книга | `book_{book_number}` | `book_1` |
| Навигация книг | `bpage_{page_number}` | `bpage_2` |
| Хадис | `hadis_{book_number}_{hadis_number}` | `hadis_1_2` |
| Навигация хадисов | `hlist_{book_number}_{page_number}` | `hlist_1_2` |
| Назад к книгам | `back_to_books` | `back_to_books` |
| Назад к хадисам | `back_to_hadis` | `back_to_hadis` |

## Особенности реализации

### 1. Ограничения Telegram
- Максимальная длина текста кнопки: 64 символа
- Максимальное количество кнопок в сообщении: ограничено, поэтому используется пагинация

### 2. Оптимизация отображения
- Названия книг и тексты хадисов укорачиваются для удобства
- Используется префикс "Х" перед номером хадиса для компактности
- Порядковые номера всегда отображаются для удобства навигации

### 3. Соответствие данных
- Каждая кнопка имеет уникальный callback_data
- Callback_data содержит всю необходимую информацию для получения данных из БД
- Порядковые номера кнопок соответствуют их позиции в общем списке

## Тестирование

Для проверки работы системы:
1. Запустите бота
2. Отправьте команду `/hadis`
3. Нажмите кнопку "Хадисы Аль-Бухари"
4. Проверьте, что все кнопки имеют порядковые номера
5. Выберите книгу и проверьте список хадисов
6. Выберите хадис и проверьте отображение текста
7. Проверьте навигацию между страницами

## Заключение

Система инлайн-кнопок полностью функциональна и обеспечивает удобную навигацию по книгам и хадисам. Каждая кнопка имеет свой порядковый номер и соответствует конкретному элементу из базы данных. Все callback_data правильно структурированы и позволяют однозначно идентифицировать выбранную книгу или хадис.
